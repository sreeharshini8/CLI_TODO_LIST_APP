# To-Do List Application

## Description
A simple console-based To-Do List application developed using Python.

## Features
- Add Tasks
- View Tasks
- Remove Tasks
- Save Tasks in a text file

## Technologies Used
- Python
- File Handling
- Lists

## How to Run
1. Open terminal.
2. Navigate to the project folder.
3. Run:
   python todo.py
